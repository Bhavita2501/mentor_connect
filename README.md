# MentorConnect

A professional platform connecting mentees with experienced industry mentors.

## Core Features

### For Mentees
- Find mentors aligned with your career goals
- Simple session booking process
- Google or email authentication
- Comprehensive session tracking

### For Mentors
- Professional profile customization
- Flexible session management
- Review-based reputation building
- Efficient booking management

### Platform Features
- Role-specific interfaces
- Session status tracking
- Responsive design
- Customizable profiles
- Global mentor network connecting professionals worldwide through a streamlined platform

## Technical Stack

### Backend
- Flask framework with SQLAlchemy ORM
- RESTful API architecture
- Google OAuth integration
- Secure session management
- Role-based access control

### Frontend
- Bootstrap 5 for responsive design
- JavaScript for dynamic interactions
- Form validation and error handling
- Real-time UI updates

### Security
- Secure authentication flow
- Data encryption
- Protected API endpoints
- Input sanitization
- Session security

### Database
- SQLite for development
- Migrations support
- Relationship management
- Data integrity constraints

## Getting Started

1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Set up environment variables
4. Initialize database: `python init_db.py`
5. Run the application: `python run.py`
